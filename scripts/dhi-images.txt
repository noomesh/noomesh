# The DHI-derived images in the org's registry, under the NESTED prefix:
# package `dhi/<name>` = ghcr.io/noomesh/dhi/<name>. Names below are written
# without the prefix.
#
# Visibility (checked 2026-10-21 with the GitHub packages API): the runtime
# images (redis, grafana, loki, prometheus, alertmanager, node-exporter,
# python) and the derived deps-core, deps-base and static-ffmpeg are PUBLIC, so
# an add-on repo (trellion-evolve builds FROM dhi/python) pulls them with no
# credential. The BUILD bases golang, rust, uv and alpine-base stay PRIVATE and
# are pulled with a credential by this repo's own lanes only. Making a package
# public or private is an org-level setting, not something these files enforce;
# this list is the declaration the mirror lanes, the Dockerfiles and the tests
# agree on.
#
#   mirror   a dhi.io mirror made by mirror-images.yml.
#   derived  built by the release on top of DHI bases (deps-core, deps-base) or
#            copied for the same build path (static-ffmpeg).
#
# The `dhi/` prefix is what lets the same names (redis, loki, ...) ALSO exist as
# upstream mirrors at ghcr.io/noomesh/<name>: the two sets must never share a
# package name.
# tests/test_image_namespace_declarations.py pins this list against the
# mirror-images.yml `auth: dhi` lanes, the Dockerfile `${DHI_REGISTRY}/` FROMs
# and the public lanes.
mirror redis

mirror tempo
mirror prometheus
mirror alertmanager
mirror node-exporter
mirror rust
mirror python
mirror uv
mirror golang
mirror alpine-base

# ci_skip_allowlist.txt — every skip the CI pytest job (`pytest tests/ -v
# --cov=noomesh --cov-report=xml`, .github/workflows/ci.yml) is allowed to
# have, and why. Enforced by tests/_ci_skip_guard.py (see
# docs/development/developer-guide.md, "A skip in CI must be explained").
#
# Format, one entry per line:
#   <glob on nodeid> | <regex on skip reason> | <justification>
# `#` comments and blank lines are ignored. All three fields are required.
#
# An entry that matches nothing in a FULL `pytest tests -q` run (no -k, no
# -m, no narrowed path args) is treated as STALE and fails the session —
# this list is meant to track real, currently-skipping tests, not to become
# a blanket exemption nobody revisits.
#
# Seeded from PR #551's CI test job (84 skipped) — categories cross-checked
# against each test file's own skip condition below.
#
# NOTE: tests/test_launch_render_parity.py is deliberately NOT listed here.
# A parallel change is making it run for real in CI (build the noo-cli
# debug binary the test needs); once that lands it must not skip, and if it
# does, that is exactly the kind of silent-guard regression this file
# exists to catch — do not add an entry to paper over it.

# ── integration/*: every integration test needs a live gateway/node-agent,
# which the CI pytest job never starts (it's a unit-test job; integration
# coverage lives elsewhere). All of these gate on an env var
# (NOO_GATEWAY_URL / NOO_NODE_AGENT_URL) or a host tool (npx) that CI does
# not provide, and fail closed (skip) rather than silently no-op.
tests/integration/test_mcp_external_door.py::* | .* | needs a live PAI gateway (NOO_GATEWAY_URL); CI's pytest job is unit-only and starts no gateway.
tests/integration/test_mcp_filesystem.py::* | .* | needs a live PAI gateway (NOO_GATEWAY_URL) and/or npx on PATH for the filesystem MCP server; CI's pytest job provides neither.
tests/integration/test_node_agent.py::* | .* | needs a live node-agent (NOO_NODE_AGENT_URL) and/or gateway (NOO_GATEWAY_URL); CI's pytest job starts neither.
tests/integration/test_persona_e2e.py::* | .* | needs a live gateway with seeded personas (NOO_GATEWAY_URL); CI's pytest job starts no gateway.
tests/integration/test_smoke_autonomy.py::* | .* | needs a live gateway with autonomy running; CI's pytest job starts no gateway.
